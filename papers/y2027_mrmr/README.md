# MRMR 2027

This package is the ICC 2027 continuation of the Multi-Resolution Multi-Robot
work. Its Python modules replicate the 2026 implementation so subsequent
paper changes can evolve independently.

`MRMR-Run.ipynb` produces one simulation result. Each
`MRMR-Visualize-*.ipynb` notebook produces one figure type from its own
exprun, and `MRMR-Flow.ipynb` executes the complete collection declared by
`mrmr2027-flow/icc-2027-all`.

Every notebook can also run independently. Select an exprun in its parameters
cell; all compatible alternatives are listed there as commented assignments.
